# Pandas for AI/ML

This repository contains beginner-friendly Pandas programs created as part of my learning journey in Artificial Intelligence and Machine Learning.

## Topics Covered

- Creating Pandas Series and DataFrames
- DataFrame attributes and data types
- Selecting rows and columns
- Filtering and sorting data
- Adding and deleting columns
- Handling missing values
- Statistical analysis
- Grouping data using `groupby()`
- Merging DataFrames
- Removing duplicate records
- Reading and writing CSV files

## Technologies Used

- Python
- Pandas

## Installation

Install Pandas using:

```bash
pip install pandas
```

## Purpose

The goal of this repository is to develop data manipulation and analysis skills needed for Data Science, Artificial Intelligence, and Machine Learning.
